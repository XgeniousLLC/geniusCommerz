Integrations

Ninety-eight providers, one integration layer.

Adding a provider is two files — a definition describing its credentials, capabilities and supported currencies, and a driver. That definition then drives the admin screens, the credential form and checkout availability. No scattered constants, no seeders to run.

Cross-border

The parts of selling abroad that usually go wrong.

Addresses that fit the country

A state dropdown where one exists, free text where it doesn't, the right postal label — ZIP, Postcode, PIN — and no postal field at all for the UAE, Hong Kong, Qatar or Panama, which have no postal system.

Money that survives an audit

Every order stores its total twice: in your base currency, which every report sums, and in the currency the customer actually saw, with the exchange rate frozen at order time. Old orders stay reconstructible years later.

Tax by destination

Country, state or postal pattern, most specific wins. Rates stack, which is how US state-plus-county and Canadian GST-plus-PST actually work. Products carry a tax class, because EU rates differ for food and books.

Templates, so setup isn't a week

One click applies EU VAT across 27 member states, UK VAT, US sales tax across 46 states, or Canada GST/HST/PST — plus shipping presets for Europe, North America and the Gulf. Re-applying skips what you already have.

Settlement

An order is paid when the gateway says so — not when the browser comes back.

This is where self-hosted carts most often get it wrong, so it is worth being explicit about how money is confirmed.

  1. The customer picks a gateway. The order is created as pending — a real state, not a guess.

  2. They're sent to pay. By redirect, by a signed form post, or by a prompt on their phone for mobile money like M-Pesa and MTN MoMo.

  3. The gateway notifies your server. The webhook signature is verified before anything is written.

  4. Only then is the order marked paid. Repeat notifications are dropped by a unique event index, so an order can't be paid twice.

The return URL never marks an order paid. A customer arriving back from a hosted page only triggers a server-to-server verification — the redirect itself proves nothing, and anyone can visit it.

Install

Running in about ten minutes.

PHP 8.2+, MySQL 8, Node 18+. Documentation covers deployment on AWS, DigitalOcean, cPanel, Docker and plain VPS.

git clone https://github.com/XgeniousLLC/geniusCommerz.git
cd geniusCommerz

composer install
npm install && npm run build

cp .env.example .env
php artisan key:generate
# set your DB_* values in .env
php artisan migrate && php artisan db:seed

Then set your store country and currency, apply a tax template, apply a shipping template, and enable a payment gateway. That's the whole setup.

Before you go live

Things we'd rather you read here than discover in production.

Test each gateway in its sandbox first. Stripe, PayPal and cash on delivery have end-to-end webhook coverage in the test suite. The rest are written against each provider's documented API and tested for structure, but not against live accounts — and webhook signature checks fail open if a field name is wrong.

Do I need all 39 payment gateways?
No. Most stores enable two or three. The rest are there so you aren't blocked the day you expand into a new market.
How is this different from WooCommerce or Shopify?
Shopify charges monthly and takes a cut unless you use their payments. WooCommerce is free, but each regional gateway, courier and tax setup is a separate paid extension. geniusCommerz ships those in the box, on a common integration layer.
Are the tax templates tax advice?
No. They're a starting point and rates change — confirm them against your own registrations. The US template carries state base rates only; counties add their own, and nexus rules decide where you must collect at all.
Does it handle EU B2B reverse charge?
Not yet. If you sell B2B into the EU, use a merchant-of-record gateway like Paddle or 2Checkout, which handles VAT on your behalf.
Is there support?
Documentation and the issue tracker are free. Paid installation, customisation and support are available through Xgenious.
